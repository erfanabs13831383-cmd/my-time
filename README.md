# جزوه تعاملی اقتصاد کلان — میان‌ترم

## اجرای محلی
فایل `index.html` را با مرورگر باز کنید. این پروژه استاتیک است و به سرور، دیتابیس یا نصب وابستگی نیاز ندارد.

## انتشار در GitHub Pages
1. یک مخزن جدید در GitHub بسازید.
2. چهار فایل این بسته را در ریشه مخزن بارگذاری کنید.
3. وارد Settings → Pages شوید.
4. در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
5. شاخه `main` و پوشه `/ (root)` را انتخاب و Save کنید.
6. لینک سایت پس از انتشار در همان صفحه نمایش داده می‌شود.

## امکانات
- درسنامه ۱۰ فصل و نقشه درختی
- فرمول‌ها، مثال‌های محاسباتی و نمودارهای SVG
- ۴۰ فلش‌کارت دسته‌بندی‌شده
- آزمون ۲۰ سؤالی با بازخورد
- چک‌لیست شب امتحان و حالت تیره
- طراحی واکنش‌گرا و راست‌چین

برخی موارد علمی متن اولیه اصلاح شده‌اند؛ از جمله تعریف ابرتورم (بیش از ۵۰ درصد در ماه در تعریف رایج)، نرخ مشارکت، تفسیر معادله مقداری پول و منحنی فیلیپس. محدوده امتحان را با تأکیدهای استاد تطبیق دهید.
