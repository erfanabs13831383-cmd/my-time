پروژه ارائه اسکرولی ALTA

ساختار موردنیاز برای انتشار:
- index.html
- segments.json
- پوشه assets/frames/ شامل ۱۳ بازه زمانی از ۰۰ تا ۱۳۰ ثانیه

انتشار روی GitHub Pages:
۱. محتویات این ZIP را مستقیماً در ریشه مخزن GitHub قرار دهید (نه اینکه خود ZIP را فقط آپلود کنید).
۲. در مخزن به Settings → Pages بروید.
۳. در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کنید؛ شاخه اصلی (معمولاً main) و پوشه /(root) را تنظیم و ذخیره کنید.
۴. پس از پایان انتشار، آدرس Pages مخزن را باز کنید.

نکات:
- فریم‌ها به فرمت WebP تبدیل شده‌اند و اندازه تصاویر یکسان‌سازی شده است.
- نمایش فریم‌ها با اسکرول انجام می‌شود؛ سایت برای بارگذاری تصاویر به وجود فایل segments.json و پوشه assets در مسیرهای نسبی مشخص‌شده نیاز دارد.
- فونت Vazirmatn از Google Fonts بارگیری می‌شود؛ در صورت نبود اینترنت، فونت جایگزین سیستم نمایش داده می‌شود.
